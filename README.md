# Field of Memories

A psychological horror mod for Minecraft 1.20.1 (Forge).

## Requirements
- Minecraft 1.20.1
- Minecraft Forge 47.x
- Java 17

## Build
Run `./gradlew build` (Windows: `gradlew.bat build`). The mod JAR is created in `build/libs/`.

Every push to `main` and every pull request runs the GitHub Actions build. Download the compiled JAR from the workflow run's **Artifacts** section.

## First milestone
- Ambient horror events in dark areas at night
- Unsettling distant sounds and visual cues
- Server-side event handling; no client-only dependency in gameplay logic

This project is an original horror setting. Features will be expanded in subsequent milestones.
